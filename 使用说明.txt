GSXT 企业信用存档助手 — 项目1

迁移位置：Mac 上你创建的 dai/1 文件夹。
将压缩包内全部文件解压到 dai/1，确保 package.json 位于 dai/1 根目录。

需要 Node.js 20 或更新版本。在该目录运行：
  npm install
  npm run install:browser
  npm test
  npm run test:browser
  npm run test:archive

使用 Chrome 扩展：
  打开 chrome://extensions，启用开发者模式。
  选择“加载已解压的扩展程序”，选择 dai/1/chrome_extension。
  点击 GSXT 扩展图标，填写企业列表，再开始执行。
  验证码需要在官网手动完成。

迁移包不包含任何账号密码、浏览器用户配置、旧 EXE 或反检测脚本。
